This module allows to display the picking barcode on the delivery slip
report. When a barcode is configured and visible for a given operation
type, it is printed below the picking reference on the delivery slip.

**Table of contents**

.. contents::
   :local:

Configuration
=============

The barcode is configured on the operation type via the
``stock_picking_form_barcode`` module. Once enabled, the barcode
automatically appears on the delivery slip report for pickings of that
operation type.
