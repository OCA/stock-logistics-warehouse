This module allows you to define specific allowed locations for products
during stock operations. When creating stock moves or transfers, only the
locations that are configured as allowed for a specific product will be
available for selection.

This capability is important when you want to ensure that certain products
can only be stored in specific locations, maintaining better control over
inventory placement and warehouse organization.

Configuration
=============

1. Go to *Inventory / Products / Products* and select a product.
2. In the product form, you will find a new tab called "Allowed Locations".
3. Add the locations where this product is allowed to be stored.
4. Save the product configuration.

Usage
=====

1. When creating stock transfers or moves, the system will automatically
   filter the available destination locations based on the product's
   allowed locations configuration.
2. If a product has no allowed locations defined, all internal locations
   will be available (default behavior).
3. The filtering applies to both product templates and product variants.
4. Changes made to the product template's allowed locations will
   automatically sync to all product variants.

Features
========

* **Product-level location control**: Define allowed locations per product
* **Automatic filtering**: Only allowed locations appear in stock operations
* **Template-variant sync**: Changes in templates automatically update variants
* **Fallback behavior**: If no locations are defined, all internal locations are available
* **Multi-location support**: Works with all stock location types
