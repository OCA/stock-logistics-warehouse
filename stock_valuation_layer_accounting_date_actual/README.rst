This module serves as a bridge between stock_move_actual_date and
stock_valuation_layer_accounting_date, updating the accounting date of
Stock Valuation Layers (SVLs) with the actual_date of the related stock
move when no related journal entry exists.

Known issues / Roadmap
======================

In future migrations, stock_move_actual_date and
stock_valuation_layer_accounting_date should be merged into one. Since
stock_valuation_layer_accounting_date is already merged, this bridge
module has been created to retain the functionality.
