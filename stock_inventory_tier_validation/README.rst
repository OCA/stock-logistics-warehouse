This module adds a tier validation process to inventory adjustments
(``stock.inventory``), so that counted quantities update stock only
after the configured reviewers have approved the adjustment.

Once a tier definition exists for inventory adjustments, on-hand
quantities can no longer be applied directly from the quants: the
*Apply* button is hidden on the counting lines, and any other attempt to
apply a counted quantity outside a validated adjustment raises an error.
The counted quantities are applied when a validated adjustment is set to
done.

Configuration
=============

Go to *Settings > Technical > Tier Validations > Tier Definition* and
create a definition for the *Inventory Adjustment Group* model.

Without any tier definition for the company, inventory adjustments
behave as in ``stock_inventory``.

Usage
=====

1. Create an inventory adjustment, press *Begin Adjustments* and enter
   the counted quantities.
2. Press *Request Validation*. While the validation is in progress, the
   counted quantities cannot be changed.
3. Once the reviewers have validated the adjustment, press *Set to
   Done*. The counted quantities are applied and the stock moves are
   created.

If the adjustment is rejected, or the stock has moved since the count,
press *Restart Validation*, correct the counted quantities and request
the validation again.
