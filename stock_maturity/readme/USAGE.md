The madurity is set by lot, as that's the whole new product quantity you're setting
for preparation.

So in order to test the module:

- Go to you're configure maturity tracked product and click on the *Update quantity* button.
- From the list, you can set a quantity of several units and create a new lot for them.
- Edit that lot and set a maturity date in the future.
- Repeat the steps with anoter lot which maturity date is in the past.
- Now create a draft delivery picking and try to deliver as many quantities you have for
  both quants and hit **Mark as Todo**.
- You'll see that only the quantity that is already mature can be reserved.
