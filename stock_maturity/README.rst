Use Cases / Context
===================

In food industries (and maybe in other sectors involving manufacturing
as well) some manufacturing procesess involve that a product might not
be ready to deliver until it passes a final madurity process.

So the product is stocked, but it isn't available until a certain
period.

Examples of these could be:

- Fruit that is store in chambers until is ripe enough.
- Dry-aged meat.
- Cheeses of all kinds.

Configuration
=============

It's configured in way very similar to expiry dates.

For product where you want to track madurity:

- Go to *Inventory > Products > Products* and chose or create one.
- In the **Inventory** tab you'll find a **Traceability** section.
- Set the **Maturity date** checkbox on.

Usage
=====

The madurity is set by lot, as that's the whole new product quantity
you're setting for preparation.

So in order to test the module:

- Go to you're configure maturity tracked product and click on the
  *Update quantity* button.
- From the list, you can set a quantity of several units and create a
  new lot for them.
- Edit that lot and set a maturity date in the future.
- Repeat the steps with anoter lot which maturity date is in the past.
- Now create a draft delivery picking and try to deliver as many
  quantities you have for both quants and hit **Mark as Todo**.
- You'll see that only the quantity that is already mature can be
  reserved.
