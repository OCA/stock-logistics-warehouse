**Standard Users:**

- *Products:* Create and edit products in your assigned categories
- *Bills of Materials:* Create and modify BOMs for products you can
  access, work normally with manufacturing specs for allowed items,
  error messages appear for restricted BOMs
- *Warehouses:* Manage inventory locations in your authorized
  warehouses, create and adjust stock locations as needed, cannot access
  restricted warehouse configurations

**Restricted Privileged Users:**

- *Products:* Work with all products without restrictions
- *Bills of Materials:* Create and modify all BOMs with full control
- *Warehouses:* Manage all warehouse locations and configurations
- *Security Settings:* Modify restricted access flags on categories and
  warehouses
