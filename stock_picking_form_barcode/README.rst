Use Cases / Context
===================

In some cases, operators begin their picking operations on a desktop and
then, use their scanner to pick products. To call the picking quickly
without searching on the barcode app, display it's convenient to display
it on picking form. s

Configuration
=============

- Go to Inventory > Configuration > Operation Types
- Choose the one you want pickings to display the picking barcode and
  check the 'Display Picking Barcode' field.
