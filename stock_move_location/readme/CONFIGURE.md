By default, the "Move from location..." wizard offers both "IMMEDIATE TRANSFER" and
"PLANNED TRANSFER". To only allow planned transfers, so that each transfer is checked
before it is validated:

1.  Go to Inventory \> Configuration \> Settings.
2.  In the Operations section, uncheck "Allow Immediate Transfer from Move Location
    Wizard".

This setting is per company. When it is unchecked, the "IMMEDIATE TRANSFER" button is
hidden from the wizard.
