This module hides the **Apply All** button on the inventory adjustment
list by default. It can be shown again for specific users by granting
them the *Apply All Inventory Adjustments* group.

**Table of contents**

.. contents::
   :local:

Use Cases / Context
===================

On the inventory adjustment list, the **Apply All** button applies the
counted quantity of every line at once. When many lines are counted,
this makes it easy to commit stock adjustments in bulk without reviewing
each line, which can lead to unintended changes that are hard to trace
afterwards.

Some organizations therefore want counts to be applied and reviewed line
by line, using the per-line **Apply** action only. This module hides the
bulk **Apply All** button from the view to enforce that workflow, while
still allowing it to be granted to trusted users through a dedicated
access group.

Usage
=====

By default the **Apply All** button is hidden for every user.

To let a specific user use it again, add them to the *Apply All
Inventory Adjustments* group (Settings > Users & Companies > Users, then
enable the group on the user).
