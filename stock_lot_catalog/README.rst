This module contains the code base that will enable the use of a lot
catalog (similar to the "Catalog" option found in certain sections of
Odoo, such as Sales or Purchases).

Use Cases / Context
===================

In some use cases, it is necessary to use lots instead of products
because the items being sold are lots, so it is useful to have the Lot
Catalog (Kanban view) feature.

Known issues / Roadmap
======================

It is intentional to have a separate codebase and not reuse anything
from ``product_catalog`` (which is added by ``product``) because
practically nothing can be reused at this time.
