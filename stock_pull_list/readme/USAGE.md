To use the module follow the next steps:

1.  Go to *Inventory \> Operations \> Generate Pull List*.
2.  Select the location to get the pull list from. Add some filtering if
    needed.
3.  Click on Prepare. You will now see the pull list with all the needs.
4.  Adjust grouping options as needed. This will generate different
    procurement groups.
5.  Click on *Procure*.

Wizard can be also launched through a server action on multiple
transfers; this is to allow user to select with ease which transfers to
include in the pull list. Please note that:

1.  To select a transfer to be included in pull list through server
    action, you first need to go to its operation type and enable field
    "Allow pull list server action".
2.  Only transfers with the same Source Location can be selected at one
    time.
