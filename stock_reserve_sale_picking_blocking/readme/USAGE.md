1.  Create a quotation with a **Delivery Block Reason** and click **Reserve
    Stock**.
2.  Click **Confirm**. No delivery order is created and the reservations stay
    active in the **Reserves** smart button.
3.  Click **Release Delivery Block**. The reservations are released and the
    delivery order is created, reserving the freed stock.

While the order is blocked, **Cancel all reservations** releases the
reservations as usual. Cancelling the order releases them once the cancellation
is confirmed in the cancel dialog, not when the dialog is opened.
