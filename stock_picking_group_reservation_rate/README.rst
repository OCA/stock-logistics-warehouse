This module allows to compute a reservation rate on picking levels that
depends on all pickings across a procurement group (same sale order,
...) and for the same picking type group (e.g.: all PICK pickings).

.. contents::
   :local:

Use Cases / Context
===================

When users want to start pickings, they want to know the reservation
rate of the pickings:

- for the same order
- across all picking zones if we have several in order to manage their
  picking operations priorities as some pickings can become available
  later.

In addition, another field allows to display the group reservation rate
of another group (e.g.: to see Pickings rate on packings level)

Configuration
=============

- Go to Inventory > Warehouse > Operation Types
- Fill in the additional picking group to monitor the reservation rate.
