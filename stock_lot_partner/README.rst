Show the partner where the serial number is.

This is meant to be used with serial numbers more than lots, because the
serial location is unique.

The standard fields are not enough because on returns it still holds the
last customer and also it does not make difference bewtween internal
locations (warehouse addresses)

Usage
=====

Go to Lots / Serial Number menu and check the partner where the lot is
